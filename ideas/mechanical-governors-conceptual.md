# Mechanical Governors for Off‑Grid Generators (Conceptual Module)

## Purpose
Engines driving generators need stable rotational speed.  
A **mechanical governor** provides passive, low‑tech speed regulation.

## What a Governor Does
- Maintains stable RPM  
- Prevents overspeed  
- Smooths load changes  
- Protects electrical equipment  

## Common Governor Types
- **Flyball (centrifugal) governor**  
- **Throttle‑linkage governor**  
- **Load‑sensing belt tension governor**  

## Integration Points
- Stirling engine output shaft  
- Steam engine throttle  
- Flywheel interface  

## Notes
This module describes the concept only.  
Exact mechanical design is left to future experts.
