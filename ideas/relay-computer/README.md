# Relay Computer Project

A resilient, legible, fully maintainable electromechanical computing architecture designed for long‑term civic use, local repair, and generational continuity.

This folder contains the complete specification, manuals, blueprints, and idea‑cards for a **relay‑based computer** built with 1920s‑level workshops, salvageable components, and community‑centered operating doctrine.

The project emphasizes:

- mechanical transparency  
- deterministic execution  
- visible and audible state changes  
- local manufacturability  
- civic trust and institutional continuity  

It is not a retro‑computing curiosity.  
It is a **design philosophy** for communities that need computation without industrial dependency.

Each appendix is self‑contained and cross‑referenced.

## 📚 Philosophy

This relay computer is built on five pillars:

### 1. Legibility Over Abstraction
Every operation is visible, audible, and inspectable.  
No silent failures. No hidden state.

### 2. Determinism Over Throughput
It is slow by modern standards, but perfectly predictable.  
This is essential for civic trust.

### 3. Mechanical Transparency
Every subsystem can be repaired with hand tools.  
Every operator can understand the machine’s behavior.

### 4. Survivability Under Loss of Industry
No silicon.  
No precision machining beyond what a small workshop can manage.  
Salvage is a first‑class design constraint.

### 5. Institutional Continuity
The machine is not just a device — it is a civic institution.  
Training, redundancy, and documentation are part of the architecture.

## 🔧 Extending the System

This project is designed to grow.

New idea‑cards, new appendices, new blueprints, and new civic workflows can be added without disturbing the core architecture.

If you add new material, place it where it naturally belongs:

- architecture changes → core files  
- operational doctrine → manuals  
- optional improvements → idea‑cards  
- environmental or social rules → appendices  

This keeps the system coherent and future‑proof.
