# Subsystem Failure Modes (Conceptual Module)

## Purpose
Resilient systems anticipate failure.  
This module outlines **conceptual failure modes** for each subsystem.

## Thermal Battery
- Overheat → dump loop or heat sink  
- Stratification collapse → mixing pump  
- Pressure rise → relief valve  

## Gasifier
- Tar condensation → preheat air  
- Channeling → grate agitation  
- Backdraft → check valves  

## Engine
- Overspeed → mechanical governor  
- Lubrication loss → shutdown  
- Temperature imbalance → airflow adjustment  

## Compressed Air
- Overpressure → relief valve  
- Moisture accumulation → drain valves  

## Notes
These are conceptual patterns, not engineering specifications.
